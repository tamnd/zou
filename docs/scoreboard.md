# Compatibility scoreboard

Generated by `zou-conformance scoreboard` and committed by CI on every merge to main, so the numbers here are the numbers the last merge measured rather than the numbers somebody last remembered to write down. There is no date in it: it changes when a number changes.

A pass means zou answered what the reference answered, byte for byte or as the same json written differently. A known difference is still counted as a failure here. It is only excused from the exit code, so this scoreboard cannot be improved by writing something down.

The questions and the recorded answers are [tamnd/zou-conformance](https://github.com/tamnd/zou-conformance) at `b8ec2511e343`.
